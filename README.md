## 📊 Análise Exploratória - Desempenho de Lojas

### 📌 Sobre o Projeto
Este projeto realiza uma análise exploratória de dados (EDA) comparativa entre quatro lojas, com o objetivo de avaliar seu desempenho em estatísticas como faturamento, média de avaliações, os produtos mais e menos vendidos, categorias de produtos e custo do frete. A análise visa fornecer insights que auxiliem na tomada de decisões estratégicas sobre quais lojas apresentam maior potencial de continuidade e investimento.

### Objetivo:

Analisar os dados e gerar insights para decisões estratégicas, nesse caso, a venda da loja com menor desempenho.


### 🛠 Ferramentas Utilizadas
Python (Pandas, Matplotlib)

Jupyter Notebook (para análise interativa)

GitHub (versionamento e documentação)

### 📝 Conclusões

Após uma análise exploratória entre as 4 lojas, pude perceber que embora a loja 4 apresente bons resultados em análises específicas, como vendas por categoria e custo médio do frete, é a loja com o menor faturamento em comparação às demais, portanto, seria a melhor opção para o Sr. João vender.

Causas possíveis que levam a ser um baixo faturamento:

* Produtos com menor valor agregado
  
Mesmo com um alto volume de vendas, os itens vendidos podem ser mais baratos em relação aos outros.

* Localização ou público-alvo
  
A localização pode atrair menos clientes ou um público pode gastar menos.

* Método de pagamento.
  
Com a opção de crédito se não houver limites parcelamentos, os clientes podem parcelar muito e a consequência disso é os juros da conversão desse crédito.

Portanto, ela seria a melhor opção para o Sr. João vender.
